🚀 SPAEDRNG-PANEL

پنل مدیریت و ایجاد کانفیگ SpaedrNG

📖 معرفی پروژه

SPAEDRNG-PANEL یک پنل مدیریت مبتنی بر Cloudflare Workers و Cloudflare Pages است که برای مدیریت سرویس‌ها، ایجاد کانفیگ و دسترسی آسان به تنظیمات شبکه طراحی شده است.

این پروژه با رابط کاربری فارسی و تمرکز بر سادگی استفاده، امکان مدیریت تنظیمات و سرویس‌های مختلف را در اختیار کاربر قرار می‌دهد.

✨ امکانات اصلی

🛡️ پشتیبانی از پروتکل‌ها
پشتیبانی از پروتکل‌های رایج مانند VLESS و سایر روش‌های اتصال سازگار با سیستم.

📊 پنل مدیریت
رابط کاربری مدیریتی برای مشاهده و مدیریت تنظیمات و کانفیگ‌ها.

🛠️ استقرار آسان
قابل استفاده روی Cloudflare Workers و Cloudflare Pages.

🔄 سیستم اشتراک
امکان ایجاد و مدیریت مسیرهای اشتراک و کانفیگ برای استفاده در کلاینت‌های مختلف.

⚡ بهینه‌سازی اتصال
امکان استفاده از تنظیمات ProxyIP و سایر گزینه‌های مربوط به مسیر اتصال.

🌐 سازگاری با دستگاه‌های مختلف
قابل استفاده در Android، Windows، iOS، macOS و سایر سیستم‌های سازگار.

⚙️ تنظیمات محیطی

متغیرهای محیطی قابل استفاده در پروژه:

متغیر| اجباری| توضیح
"ADMIN"| ✅| رمز ورود پنل مدیریت
"KEY"| ❌| کلید مسیر اشتراک
"UUID"| ❌| UUID ثابت برای کانفیگ
"PROXYIP"| ❌| آدرس ProxyIP
"URL"| ❌| آدرس صفحه پیش‌فرض
"GO2SOCKS5"| ❌| تعیین دامنه‌هایی که از SOCKS5 استفاده کنند
"DEBUG"| ❌| فعال یا غیرفعال کردن لاگ‌های دیباگ
"OFF_LOG"| ❌| فعال یا غیرفعال کردن ثبت لاگ
"BEST_SUB"| ❌| فعال‌سازی قابلیت اشتراک بهینه
"PRELOAD_RACE_DIAL"| ❌| فعال‌سازی اتصال پیش‌بارگذاری‌شده
"TCP_CONCURRENT_DIAL"| ❌| تعداد اتصال‌های همزمان TCP
"PROXY_CONCURRENT_DIAL"| ❌| تعداد اتصال‌های همزمان Proxy

🔧 تنظیمات پیشرفته

استفاده از ProxyIP

می‌توان ProxyIP را از طریق مسیر یا پارامتر تنظیم کرد:

/proxyip=example.com
/?proxyip=example.com

استفاده از SOCKS5

/socks5=user:password@127.0.0.1:1080

یا:

/socks5://user:password@127.0.0.1:1080

استفاده از HTTP Proxy

/http=user:password@127.0.0.1:8080
